# 💰 MyFinam — Личный финансовый помощник

**MyFinam** — это backend-приложение для автоматизации личного финансового учета. 
Проект позволяет подключать банковские API и отслеживать расходы без ручного ввода.

---

## 🚀 Ключевые возможности

## Integrations

Приложение `integrations` отвечает за интеграцию с API внешних банков. Обеспечивает:
- OAuth2-авторизацию в банках (Тинькофф, Сбер и др.)
- Автоматическую выгрузку транзакций пользователя
- Нормализацию данных из разных банков в единый формат
- Дедупликацию транзакций
- Фоновую синхронизацию через Celery

### 🤖 Автоматическая синхронизация с банками
- Интеграция с **Тинькофф**, **Сбер**, **Райффайзен** через OpenAPI
- OAuth2-авторизация с зашифрованным хранением токенов
- Фоновая синхронизация транзакций каждые 3 часа
- Защита от дублирования данных

### 💸 Управление финансами
- Счета с поддержкой разных валют
- Доходы, расходы и переводы между счетами
- Иерархические категории трат
- Бюджетирование с контролем лимитов

### 📊 Аналитика и отчеты
- Общий баланс и динамика
- Статистика по категориям и периодам
- Топ расходов и доходов
- Прогресс выполнения бюджетов

### 🔔 Умные уведомления
- О превышении бюджета
- О скорых списаниях по подпискам
- Еженедельный дайджест по финансам

### 🎯 Финансовые цели
- Отслеживание накоплений
- Расчет необходимой суммы и срока достижения
- Визуализация прогресса

## 🛠 Технологический стек

| Компонент | Технология |
|-----------|------------|
| **Backend** | Python 3.13, Django 5 |
| **API** | Django REST Framework, JWT |
| **База данных** | SQLite (разработка) / PostgreSQL (продакшн) |
| **Шифрование** | django-fernet-encrypted-fields |
| **Асинхронность** | Celery + Redis |
| **Документация** | OpenAPI (drf-spectacular) |

## 📡 API Endpoints

### Пользователи
```
POST   /api/users/register/     # Регистрация
POST   /api/token/              # Получение JWT
POST   /api/token/refresh/      # Обновление токена
```

### Интеграция с банками
```
POST   /api/integrations/connect/tinkoff/   # Подключение Тинькофф
GET    /api/integrations/callback/          # OAuth2 callback
POST   /api/integrations/sync/              # Ручная синхронизация
GET    /api/integrations/connections/       # Список подключений
```

### Финансы
```
GET    /api/accounts/          # Счета
GET    /api/transactions/      # Транзакции
GET    /api/categories/        # Категории
GET    /api/budgets/           # Бюджеты
GET    /api/goals/             # Цели
GET    /api/subscriptions/     # Подписки
```

### Аналитика
```
GET    /api/analytics/summary/           # Общая сводка
GET    /api/analytics/monthly-expenses/  # Расходы по месяцам
GET    /api/analytics/top-categories/    # Топ категорий
```

### Пример ответа аналитики
```json
{
  "income": 150000,
  "expenses": 70000,
  "balance": 80000,
  "savings_rate": 46.7,
  "top_category": "Рестораны",
  "budget_completion": 82
}
```

## ⚙️ Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/Lyclent/MyFinam.git
cd MyFinam
```

### 2. Настройка виртуального окружения
```bash
python -m venv venv
source venv/bin/activate      # Linux/Mac
venv\Scripts\activate          # Windows
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения
```bash
# Создайте файл .env в корне проекта
cp .env.example .env

# Добавьте в .env:
SECRET_KEY=your-secret-key-here
ENCRYPTION_KEY=your-fernet-key
```

### 5. Миграции и суперпользователь
```bash
python manage.py migrate
python manage.py createsuperuser
```

### 6. Запуск сервера
```bash
python manage.py runserver
```

Сервер запустится на `http://localhost:8000`
